# Project Status

**Last updated:** September 2026  
**Overall stage:** Pre-manufacturing validation

## Completed

- Laboratory mission and safety rules documented
- Robot-platform standards drafted
- Multiple robot families defined at concept/pre-prototype level
- Ninja Bot lead platform selected
- Universal armor R0 CAD-generation package and STL exports created
- Prototype assembly and validation plans created
- B.O.X.-1 ESP32 learning prototype built previously
- Bambu Lab Let's Make It Fund application submitted

## Next physical milestones

1. Print HD-USA-1S receiver and latch fit coupons.
2. Measure fit, clearance, retention, release and wear.
3. Revise geometry and repeat.
4. Assemble protected Ninja drivetrain test hardware.
5. Pass stationary power and emergency-stop testing.
6. Pass raised-wheel and low-speed floor testing.
7. Integrate sensing, visible scanning and removable armor.
8. Build the second robot only after the first platform passes its gates.

## Current limitation

Harris Dynamics does not yet have an in-house 3D-printer cell. Digital files and plans are therefore not represented as physically validated components.
