# Security and Disclosure Policy

Harris Dynamics public repositories must not contain:

- Wi-Fi names or passwords
- API keys, tokens or authentication files
- Private addresses, telephone numbers or account records
- Unredacted personal information
- Confidential third-party material
- Unreleased manufacturing files designated as protected

AI-assisted concept images must be labeled. They communicate design intent and are not proof of a completed prototype.

Security issues should be reported privately rather than opened as a public issue. A dedicated security contact process will be added before public source-code releases begin.
